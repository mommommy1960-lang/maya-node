# Reviewers Start Here

Maya Node is a governance and control architecture for separating technical capability from human authorization.

## Review focus

Test scoped permissions, expiration, revocation, consent tokens, audit evidence, and human override paths.

## Evidence boundary

This is a prototype and design-review system. It is not legal certification, penetration testing, or a guarantee of production safety.

## Ownership

Mya P. Brown and the Commons Initiative retain ownership. Reviewers may propose changes through pull requests; no access grants ownership or relicensing rights.

Start with [public due diligence](docs/PUBLIC_DUE_DILIGENCE_START_HERE.md), then inspect [SECURITY.md](SECURITY.md) and [CODEOWNERS](.github/CODEOWNERS).
