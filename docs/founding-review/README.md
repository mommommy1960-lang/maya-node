# Maya Node Founding Review — Fulfillment Kit

This directory is the operating kit for the first three paid Maya Node Founding Reviews.

## Customer path

1. Customer reads the [public offer](../MAYA_NODE_FOUNDING_REVIEW.md).
2. Customer purchases one $25 founding review through the linked Stripe checkout.
3. The founder sends the [intake questions](CUSTOMER_INTAKE.md).
4. The submitted material is checked against the [service boundaries](TERMS_AND_BOUNDARIES.md).
5. One relevant adversarial test is designed and recorded with [ADVERSARIAL_TEST_RECORD.md](ADVERSARIAL_TEST_RECORD.md).
6. Findings are written with [REPORT_TEMPLATE.md](REPORT_TEMPLATE.md).
7. The report is delivered with [DELIVERY_EMAIL.md](DELIVERY_EMAIL.md).
8. The privacy-safe status ledger is updated without customer names, email addresses, source files, or confidential findings.

## Service truth

This is a human-delivered design review of consent, authority, revocation, auditability, and fail-closed behavior. It is not automated certification, legal advice, penetration testing, a safety guarantee, or production approval.

The first release is intentionally capped at three completed founding reviews. Expansion requires evidence that the workflow is understandable, repeatable, safe to deliver, and worth purchasing.
