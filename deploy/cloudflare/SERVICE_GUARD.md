# Persistent service guard

Source implementation, not verified deployed. Thirty local Node test cases/check entries passed on October21,2026 across guard, existing queue, Stripe, request limits and health reporting. Local SQLite and mocked network only; Cloudflare D1, production secrets, actual mail and alert receipt remain unverified.

New schema creates service_guard paused by default. For existing databases, an authorized deployment must create ONLY the new service_guard table and paused row; do not rerun the original jobs schema on an existing database or wipe jobs. Back up and verify restoration first. Deploy code while existing SEND_ENABLED remains false. Exercise a fresh synthetic job and pause in staging. An authorized operator may set paused=0 only after inspecting unresolved jobs, cause, configuration and recovery evidence. No automatic resume endpoint is supplied. Do not call the code active until the deployed revision, schema, negative test and alert receipt are verified.

Dispatch commitment is one conditional SQL statement that requires unpaused state and no unknown or dispatch_committed jobs. This is the cutoff: a pause cannot recall a request already committed to a provider. Unknown provider outcomes remain held for reconciliation, never automatically resent. Provider failures latch pause; scheduled OAuth/runtime failures and preexisting interrupted jobs latch pause. Missing guard schema blocks dispatch. Read-only health stays available. GET /guard and POST /guard/pause require existing controller bearer token. No new access or secrets added.

Scope: Maya Cloudflare email queue ONLY, not every Civic Continuum website or product. This does not detect natural hazards, account cash shortages, all billing anomalies or cyberattacks. Stripe signature and order validation remain in place; no payments/refunds are initiated. Health webhook still needs configured independent receiver; existing alert delivery lacks durable retry. Database outage denies effects but may prevent durable latch until storage recovers. No data backup system is created by this change.
